# اپلیکیشن محراب (Mihrab)

برنامه مدیریت آفلاین نمازهای قضا، روزه، ادعیه و محاسبه‌گر زکات و فطریه.

## 🚀 راهنمای اجرای برنامه در سیستم شخصی (کامپیوتر/موبایل)

توجه داشته باشید که پروژه با **React + Vite + TypeScript** توسعه یافته است. فایل‌های `.tsx` به صورت مستقیم توسط مرورگر قابل خواندن نیستند و دوبار کلیک روی فایل `index.html` باعث نمایش صفحه سفید می‌شود (زیرا مرورگر فایل‌های ماژول React را به دلایل امنیتی CORS در حالت `file://` اجرا نمی‌کند).

برای اجرای صحیح برنامه یکی از دو روش زیر را دنبال کنید:

### روش اول: اجرای حالت توسعه (Development)
1. ترمینال (Terminal یا Command Prompt) را در پوشه پروژه باز کنید.
2. دستور زیر را برای نصب پیش‌نیازها اجرا کنید:
   ```bash
   npm install
   ```
3. دستور زیر را برای اجرای سرور محلی بزنید:
   ```bash
   npm run dev
   ```
4. آدرس ارائه شده (مثلاً `http://localhost:3000`) را در مرورگر باز کنید.

---

### روش دوم: ساخت نسخه نهایی جهت انتشار یا مشاهده نسخه خروجی (Production Build)
1. ترمینال را در پوشه پروژه باز کرده و دستورات زیر را اجرا کنید:
   ```bash
   npm install
   npm run build
   ```
2. پس از اتمام دستور بالا، پوشه جدیدی به نام `dist` ساخته می‌شود.
3. برای مشاهده نسخه خروجی، دستور زیر را بزنید:
   ```bash
   npm run preview
   ```
4. اگر می‌خواهید سایت را روی GitHub Pages، Vercel، Netlify یا هر هاست دیگری آپلود کنید، کافی است **محتویات داخل پوشه `dist`** را آپلود نمایید.

---

## 🌐 انتشار روی GitHub Pages (حل مشکل صفحه سفید در لینک گیت‌هاب)

علت نمایش صفحه سفید در لینک `https://amirhd2.github.io/Mihrab/` این بود که گیت‌هاب سورس‌کد خام (`src/main.tsx`) را به جای پوشه کامپایل‌شده `dist` سرو می‌کرد. برای حل ریشه‌ای این موضوع:

### فعال‌سازی انتشار خودکار (GitHub Actions)
1. وارد ریپازیتوری خود در گیت‌هاب شوید (`https://github.com/amirhd2/Mihrab`).
2. به تب **Settings** بروید.
3. از منوی سمت چپ، گزینه **Pages** را انتخاب کنید.
4. در بخش **Build and deployment**، گزینه **Source** را روی **GitHub Actions** قرار دهید.
5. فایل اکشن `.github/workflows/deploy.yml` که به پروژه اضافه شده است، با هر `git push` به صورت خودکار پروژه را بویلد کرده و نسخه `dist` را روی لینک شما قرار می‌دهد!

### یا انتشار دستی با یک دستور (Manual Deploy)
می‌توانید در ترمینال سیستم خود دستور زیر را اجرا کنید تا مستقیماً روی شاخه `gh-pages` منتشر شود:
```bash
npm run deploy
```
